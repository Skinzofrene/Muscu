# Descriptions techniques V5

Cette version applique les décisions humaines de résolution visuelle sans modifier les prescriptions, les progressions, le schéma des données ni la logique du programme.

Les précisions ont été ajoutées dans `dist/technical-catalog.js`. L’architecture existante de `dist/technique.js` continue de dériver automatiquement `detailedInstructions`, `sessionCue` et `sessionCues` à partir de ce catalogue canonique : aucun second texte technique indépendant n’a été créé.

Principaux renforcements :

- assistance un bras par prise du poignet ou de l’avant-bras distal ;
- distinction rowing asymétrique, archer et unilatéral assisté ;
- pieds surélevés sur support stable pour le rowing dédié ;
- pont fessier à levier long au sol, sans sangle ni support mobile ;
- variantes hollow, walkout unilatéral, side plank genou et planches asymétriques ;
- séquences textuelles complètes pour wall slide, prone W et Y-T-W ;
- quatre directions explicites pour les isométriques du cou ;
- définitions sans banc ni prise extérieure pour le reverse crunch à levier long ;
- spécifications techniques des Copenhagen et relevés tibiaux restant à illustrer.
