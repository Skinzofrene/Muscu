## Règle de classement

- **OK** : héritage de base et écarts de variante cohérents.
- **CORRECTED** : contradiction d’orientation, d’appui, de type ou d’exécution supprimée.
- **DECISION_REQUIRED** : plusieurs interprétations restent légitimes; le programme est conservé sans inventer la mécanique.
- **REDUNDANT** : mécanique identique à une autre variante; seule la prescription ou une intensité implicite change.
